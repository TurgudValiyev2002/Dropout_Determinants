# Tuned Full-Feature vs Ablation Study Report

This comparison uses only tuned models. For each ablation block, the model was selected using validation Macro-F1, with balanced accuracy and log-loss used as secondary criteria. The same rule was used for the full-feature model. Train, validation, and test results were then compared to avoid judging models from one split only.

The tuned full-feature benchmark selected **LightGBM** using 36 raw predictors and 244 encoded features. It achieved train Macro-F1 = 0.8891, validation Macro-F1 = 0.7088, and test Macro-F1 = 0.7016. Its test balanced accuracy was 0.7892, and test log-loss was 0.5902. The train-to-test gap is visible but not extreme, suggesting useful generalization with some remaining complexity from the full feature space.

Among the ablation blocks, the strongest validation-selected block was **2.Academic + demographic-financial** with **LightGBM**. It reached train Macro-F1 = 0.8588, validation Macro-F1 = 0.7022, and test Macro-F1 = 0.6983. Compared with the full-feature tuned model, this block was only 0.0032 Macro-F1 lower on test, 0.0040 lower in balanced accuracy, and 0.0311 higher in log-loss. This is a very important result: most of the full model's predictive value is recovered by combining academic variables with demographic/financial variables.

Academic-only performance was clearly lower than the full-feature model and the demographic/financial block. The academic-only tuned model reached test Macro-F1 = 0.6534, balanced accuracy = 0.7523, and log-loss = 0.6638. Adding demographic/financial variables increased test Macro-F1 by 0.0449 and improved test balanced accuracy by 0.0329. This supports a strong policy interpretation: tuition status, debtor status, scholarship, age, and related demographic/financial signals add meaningful information after academic performance.

The parental, macroeconomic, and course/application blocks gave weaker gains. Academic + parental education reached test Macro-F1 = 0.6695, which is above academic-only but still below the demographic/financial block. Academic + macroeconomic reached test Macro-F1 = 0.6584, and academic + course/application reached 0.6546. These results suggest that parental education, macroeconomic context, and course/application information may contribute marginally, but they do not explain dropout risk as strongly as direct academic and financial/demographic indicators.

For the paper, the key message should be: **the full-feature model provides the highest maximum-information benchmark, but the academic + demographic/financial ablation block nearly matches it on the test set.** This makes the findings more actionable for universities because the strongest added value comes from variables linked to financial vulnerability and student profile rather than broad macroeconomic or parental-background variables. The recommended table is `paper_ready_tuned_full_vs_ablation_comparison.csv`, and the strongest interpretation is based primarily on test Macro-F1, test balanced accuracy, and test log-loss, with validation results used only for model selection.
